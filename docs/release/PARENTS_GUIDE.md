# 手机端日常使用指南

> 状态：`Active` · 面向家庭成员（`dad` / `mom` / `son`）的手机 PWA 日常记账与协作说明。

## 1. 首次登录与添加到主屏幕

1. 用手机浏览器打开家庭账本网址（本地体验 `http://localhost:5200/`，正式部署 `https://<你的域名>/`）。
2. 输入用户名（`dad`、`mom` 或 `son`）。
3. **首次登录先点下方「密码登录」**，输入初始密码（未绑定 Passkey 前请勿直接点「使用 Passkey 登录」）。
4. 登录后可在 **我的 → Passkey 与登录方式** 录入指纹/面容；也可通过浏览器菜单 **添加到主屏幕**，无需安装 APK。

## 2. 底部导航与常用操作

- **首页 / 流水**：查看当月收支概览与交易明细（本地虚构演示库的数据固定在 `2026-08` 与 `2026-09`）。
- **中间「+」记一笔**：记录当前时间的 **支出**、**收入** 或 **转账**（转账需选不同的同币种账户；外币交易需填写折合人民币金额；退款与发起新分摊在桌面管理台完成）。
- **分摊**：查看待确认的家庭分摊，可 **接受** 或填原因 **退回**；若原支出被修改，分摊会自动重置为待重新确认。
- **我的 → 导入账单**：上传 `CSV / TSV / XLSX`（启用 OCR 后支持 `PDF / 图片`），在候选区核对分类、未指定的目标账户与重复提示后确认入账；确认后未改动、未分摊、未退款且未锁账的批次支持整批撤销。

## 3. 隐私与权限边界

- **个人账户默认私密**：个人账户仅归属人可见；涉及他人未授权个人账户的往来自动显示为 **私人账户（已脱敏）**，同时保持总账借贷平衡。
- **桌面管理台**：仅管理员（`son`）可通过 **我的 → 桌面管理台**（`/admin.html`）管理分类、账期锁定、5 层级 XLSX 报表与加密备份。
