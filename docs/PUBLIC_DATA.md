# 公开数据范围

本仓库是可独立运行的源码快照，使用全新 Git 历史。示例数据库由 `backend/scripts/build_demo_database.py` 从零构建，不是对真实数据库替换姓名后的副本。

## 包含

- 当前 FastAPI / React 主版本、数据库迁移、自动化测试和部署模板。
- 完全虚构的演示数据库与 CSV；示例库的密码哈希清空，运行演示时重新生成本地密码。
- 前端已有的开发 mock 与单元测试 fixture；这些代码仅用于演示和测试，真实 API 模式默认启用。
- 环境变量名称和占位符；不包含有效的服务密钥。

## 排除

- 本地及服务器真实数据库、原始 CSV / PDF / 图片账单、加密源文件和备份。
- 登录密码、密码哈希、Cookie、令牌、Passkey、模型登录凭据与真实 `.env`。
- 运行日志、AI 输入输出、浏览器截图、自动化会话、发布压缩包、内部交接文档。
- 旧版原型、私人业务约定和原仓库的历史提交。

## 校验

`check_public_demo.py` 验证示例库完整性、外键、凭据及运行表为空、虚构交易白名单和复式借贷平衡。`.gitignore` 默认忽略运行数据、数据库、密钥和日志，仅放行指定示例库与源码中的类型 / mock 目录。

这些措施覆盖本次公开快照。未来导入的真实数据仍需保存在忽略目录，不应强制 `git add -f` 上传；业务 CSV 导出不等于脱敏，导出文件也可能包含真实财务信息。
