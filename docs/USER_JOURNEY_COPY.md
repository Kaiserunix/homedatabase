## 2. 家庭角色与权限沙盒指南（`dad` / `mom` / `son` 角色映射文案）

当前 V1 数据库模型（`backend/src/homedatabase_api/models.py:85`）内置了开箱即用的三角色家庭权限沙盒。无论是三口之家、二人新婚夫妻，还是个人多账户管理，均可按以下指南直接使用：

| 预置账号 | 默认显示名 | 系统权限角色 | 适用家庭成员建议 | 可访问入口与权限边界 |
| :---: | :---: | :--- | :--- | :--- |
| **`son`** | 儿子 | **管理员 (`isAdmin=true`)** | **家庭管账主理人**<br>（三口之家的子女，或二人夫妻家庭中负责管账/部署的一方） | • 可登录手机端（`/`）与**桌面管理台（`/admin.html`）**<br>• 可管理分类、执行期间封账锁定、创建/校验加密备份、导出五层 XLSX 报表<br>• **隐私边界**：即使是管理员，在未获授权前也**看不到** `dad` 或 `mom` 的个人私有账户余额与明细！ |
| **`mom`** | 妈妈 | **家庭成员 (`isAdmin=false`)** | **伴侣 / 妈妈** | • 可登录手机端 PWA（`/`）随时记账、导入个人或共享账户的 CSV/XLSX 账单、处理家庭分摊<br>• 个人私有账户默认仅本人可见；跨私有账户转账在对方视角自动脱敏为 `私人账户（已脱敏）` |
| **`dad`** | 爸爸 | **家庭成员 (`isAdmin=false`)** | **伴侣 / 爸爸** | • 与 `mom` 对等：拥有独立的个人私有账户、Passkey 生物识别凭证与家庭公共账户视野 |

## 3. 父母与家人手机端日常使用口袋书（替代 `docs/release/PARENTS_GUIDE.md`）

> 以下内容可直接打印或发在「相亲相爱一家人」微信群，供爸妈或伴侣 1 分钟上手。

### 第一步：第一次打开与登录（只需 1 分钟）
1. 在手机浏览器打开家庭账本网址，点击底部或顶部的 **「添加到主屏幕」**，把它放到手机桌面上。
2. 在登录框上方输入你的账号名（**`mom`**、**`dad`** 或 **`son`**）。
3. **重点提示**：第一次登录时，请先点开页面下方的 **「🔑 密码登录 ⌄」**，输入初始密码登录。
4. 登录成功后，点右下角 **「我的 → Passkey 与登录方式 → 添加 Passkey」**，按一次指纹或刷一下脸。以后打开账本，直接点最大的 **「使用 Passkey 登录」** 就能一秒进账本，再也不用背密码！

### 第二步：日常随手记一笔（3 秒搞定）
1. 点手机底部正中间的 **`+`（记一笔）**。
2. 选择 **「支出」**、**「收入」** 或 **「转账」**（例如提现、还信用卡请选择「转账」）。
3. 输入金额（如 `35.80`）和账面名称（如 `菜市场买排骨`），点选一个分类图标和付款账户，点 **「保存」** 即可。

### 第三步：月底导入微信 / 支付宝账单（防重、防错、可随时反悔）
1. 从微信或支付宝导出本月的账单表格（CSV 或 XLSX 文件）到手机里。
2. 打开账本底部 **「我的 → 导入账单」**，选择刚导出的文件和对应的账户，点 **「开始导入」**。
3. **安心复核（不会直接乱入账！）**：
   - 文件解析后，会先停在 **「待确认批次」** 里；
   - 如果某笔账以前已经记过了，系统会自动标上黄色的 **`[疑似重复]`** 并帮你**取消勾选**；
   - 如果有外币消费，会标上 **`[待补汇率]`**，填好折合人民币金额点保存即可；
   - 你可以逐条检查或修改分类，核对无误后点右下角的 **「确认入账」**，这批账单才会真正写进账本。
4. **导错了怎么办？**
   - 完全不用慌！在「导入账单 → 历史批次」里找到刚才那批账单，点红色的 **「整批撤销」**，整批账单就会干干净净地撤回，账本恢复原样。

### 第四步：家庭 AA 与公共开支分摊
1. 当家里有人发起了公共开支分摊（比如全家旅游、物业水电费），你的手机首页「待办」会出现 **`X 笔分摊待你接受`**。
2. 点进去看清楚总额和「我应摊」的金额：
   - 没问题就点 **「接受」**（只有你点接受后，分摊才会正式生效）；
   - 如果金额不对或你不参与这笔消费，点 **「退回」** 并写一句理由（如 `这笔我已经付过现金了`），对方就会收到你的退回说明。

## 4. 核心界面关键状态微文案速查卡（UI Microcopy Tokens）

### 4.1 批次导入 8 态精准微文案（`Import.tsx` / `Imports.tsx` / `ImportDetail.tsx`）

| 状态枚举 (`BatchStatus`) | 视觉色调 (`tone`) | 手机/桌面统一徽标文案 | 状态栏辅助说明微文案 |
| :--- | :---: | :--- | :--- |
| `queued` | `neutral` | **排队中** | `账单文件已加密上传，正在等待解析队列处理…` |
| `processing` | `accent` | **解析中** | `正在校验表头、解析金额并与历史流水比对去重（{filesProcessed}/{fileCount}）…` |
| `reviewing` | `warn` / `accent` | **待确认** | `已解析出 {candidateCount} 条候选账目，核对分类与账户后点击「确认入账」才会写入账本。` |
| `needs_ocr` | `warn` | **待人工/OCR识别** | `PDF 或图片账单需完成 OCR 识别并人工复核后才能入账（当前尚未写入账本）。` |
| `rejected` | `warn` / `danger` | **已拦截 / 无法解析** | 若为重复文件：`该文件与此前上传的账单完全一致，已自动跳过以防重记。`<br>若为格式错误：`未能识别有效的账单表头或收支列，请参考 CSV 模板调整后重试。` |
| `failed` | `danger` | **解析失败** | `文件解析过程中出现异常：{message}。原始账本未受任何影响。` |
| `posted` | `ok` | **已入账** | `已确认写入账本。如发现导错账户或文件，可点击「整批撤销」一键回滚。` |
| `undone` | `neutral` | **已撤销** | `该批次已入账的交易已全部无痕撤销，并已记录审计日志。` |
